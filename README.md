# Crystal Road — Web build

Playable development build of **Crystal Road** (Rululu Studio), built with Unity 6000.4.4f1 for the Web.

- Play: https://rululu-studio.github.io/Crystal-Road-Web/
- This repository contains only the compiled Web build (HTML, JavaScript, WebAssembly and packed game data).
  Game source code and source art are not published here.
- Files are stored uncompressed because GitHub Pages cannot send custom `Content-Encoding` headers.
